# Keybindings

Comet v0.1.0 follows MComix behavior for the reader functions implemented in this release.

| Action | Binding |
|---|---|
| Open | Ctrl+O |
| Close book | Ctrl+W |
| Quit | Ctrl+Q |
| Next page/spread | PageDown, left click |
| Previous page/spread | PageUp, Backspace |
| Smart scroll forward | Space, mouse wheel down |
| Smart scroll backward | Shift+Space, mouse wheel up |
| One page forward in double-page mode | Ctrl+PageDown / Ctrl+Space |
| One page backward | Ctrl+Shift+PageDown / Ctrl+Shift+Space |
| Direction-aware one-page navigation | Alt+Left / Alt+Right (reversed in manga mode) |
| First / last page | Home / End |
| Previous / next archive | Ctrl+Shift+P / Ctrl+Shift+N |
| Best Fit | B |
| Fit Width | W |
| Fit Height | H |
| Manual 100% | A |
| Zoom in / out | + / - or Ctrl+mouse wheel |
| Reset temporary zoom | Ctrl+0 |
| Double-page mode | D |
| Manga mode | M |
| Stretch small images | Y |
| Fullscreen | F / F11 |
| Hide/show UI chrome | I |
| Add bookmark | Ctrl+D |
| Open bookmark list | Ctrl+B |

The reference for compatible behavior is the MComix keybindings documentation. Comet is an independent implementation and does not contain MComix source code.
